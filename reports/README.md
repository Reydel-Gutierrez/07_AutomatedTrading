# Reports

Research, candidates, theses, allocation, benchmark vs SPY.

Size as **% of current NAV**. Do not write NAV-tier strategies.

## Prefixes

`YYYY-MM-DD_regime.md` · `_candidates.md` · `_research_<SYM>.md` · `_thesis_<SYM>.md` · `_allocation.md` · `_benchmark.md` · `_promotion.md` · `_review.md`

## Conventions

- `live_trade_actions_allowed: false`
- No review/place/transfers
- Candidate ≠ thesis ≠ order
- Facts vs interpretation
- Classification evidence required for 25%/40% buckets
- Holdings count is reported, not a cap
